from pyspark.sql import SparkSession
from transformers import AutoTokenizer, AutoModel
from qdrant_client import QdrantClient

# 1. Pipeline de Ingesta & Limpieza
df = spark.read.parquet("s3://data-lake/raw_corpus/")
cleaned_df = df.filter(df.quality_score > 0.85)

# 2. Generación de Embeddings para LLM
model = AutoModel.from_pretrained("BAAI/bge-small-en-v1.5")
vectors = model.encode(cleaned_df.select("text"))

# 3. Carga en Base de Datos Vectorial
qdrant.upsert(collection="knowledge_base", points=vectors)
# Status: Ready for RAG & Fine-Tuning

Sobre Mí & Enfoque Técnico

"La calidad de un modelo de IA está limitada por la calidad de la infraestructura de datos que lo alimenta."

Infraestructura como Pilar para IA

Mi objetivo primario a corto plazo es consolidarme como Junior Data Engineer. Entiendo que los modelos de lenguaje (LLMs) y los sistemas de Machine Learning no pueden funcionar de manera confiable sin flujos de datos limpios, reproducibles y eficientes en costos. Me especializo en diseñar pipelines ETL/ELT estructurados con Python, SQL, Docker y PySpark.

Visión a Largo Plazo: LLMOps / MLOps

Mi hoja de ruta evoluciona hacia el rol de LLMOps Engineer. Me apasiona cerrar la brecha entre la ingeniería de datos tradicional y la puesta en producción de modelos de lenguaje. Trabajo activamente con bases de datos vectoriales (Qdrant, ChromaDB), arquitecturas RAG, orquestación de embeddings y la curaduría de datasets sintéticos para fine-tuning.
